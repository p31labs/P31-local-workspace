## FULL DESCRIPTION

P31 Labs, Inc. is a Georgia domestic nonprofit corporation (EIN 42-1888158, incorporated April 3, 2026) building open-source assistive technology grounded in the invariant tetrahedral geometry that emerges at every scale — from quantum coherence to social resilience.

Our work spans three intersecting areas:

1. **BONDING** — An open-source, zero-dependency chemistry game for neurodivergent learners that uses K₄ complete graph topology as its core gameplay mechanic. It's a cognitive prosthetic: teaches systems thinking through play, with 426 passing tests and full offline PWA support. Built with TypeScript + React + R3F.

2. **Floating Neutral Hypothesis** — Research translating lived experience with hypoparathyroidism (permanent endocrine condition causing basal ganglia calcification) into actionable biomedical and assistive technology. We model calcium-phosphate disruption as a "floating neutral" in biological voltage regulation, creating tools for seizure-threshold monitoring and calcium homeostasis tracking.

3. **LOVE Ledger** — A care-economy protocol using tetrahedral consensus for distributed, non-extractive community support transactions. The "LOVE" acronym stands for Local, Open, Verifiable, Empathy-based exchange.

All projects are published under OIN 2.0 / MIT / GPLv3 (firmware: GPLv3; hardware: CERN-OHL-S; datasets: CC0). We operate as a pure public good with zero venture capital, no equity structure, and no external fiscal sponsor.
