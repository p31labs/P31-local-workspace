# Component Catalog

P31 design system components are the building blocks of all P31 surfaces. Every component is neuroinclusive by design — respecting spoon levels, glassmorphism, and quantum-cyan accent rules.

---

## Core Components

These components live in `packages/design-core/src/generated/` and are the single source of truth.

### Crown
The P31 Crown mark — a 200×168 SVG icon symbolizing cognitive sovereignty. Acts as the site-wide brand mark and navigation anchor.

- **ViewBox:** `0 16 200 168`
- **Accessibility:** Includes `<title>` and `<desc>` elements
- **Variants:** Icon-only (full P31 tetrahedral mark)
- **Import:** `import { Crown } from '@p31/design-core/generated/Crown'`

### GlassCard
The canonical glassmorphic card container. Wraps content with the P31 glass aesthetic.

- **Glass tier:** Standard (`.glass-panel` base)
- **Hover:** Lifts 2px, border brightens
- **Import:** `import { GlassCard } from '@p31/design-core/generated/GlassCard'`

### Button
Three-variant button component with quantum-cyan primary accent.

- **Variants:** `primary` | `secondary` | `ghost`
- **Sizes:** `sm` | `md` | `lg`
- **Accessibility:** `min-height: 44px`, `min-width: 44px`, focus-visible ring
- **Import:** `import { Button } from '@p31/design-core/generated/Button'`

### SpoonDial
Cognitive load indicator and adjustment control. Shows current spoon level (0–5) with mode switching.

- **Modes:** Full dial, compact icon, hidden (crisis)
- **Import:** `import { SpoonDial } from '@p31/design-core/generated/SpoonDial'`

### CrisisOverlay
Full-screen breathing overlay for crisis mode (spoons = 0). Only exit control is visible.

- **Behavior:** Renders when `data-spoons="0"`
- **Controls:** Escape key, "I'm ready" button
- **Import:** `import { CrisisOverlay } from '@p31/design-core/generated/CrisisOverlay'`

## UI Chrome Components

These components live in `packages/ui/src/chrome/` and are available via `@p31/ui/chrome`.

### SiteNav
Primary navigation with candy-pill segments and active state detection.

- **Features:** Route-based active highlighting, tetrahedral nav structure
- **Import:** `import { SiteNav } from '@p31/ui/chrome'`

### BrandMark
App-specific brand identity with icon + name + tagline.

- **Props:** `appName`, `tagline`, `icon`

### Footer
Standard P31 site footer with links, copyright, and mesh status.

- **Import:** `import { Footer } from '@p31/ui/chrome'`

WCAG 2.2 skip-navigation link for keyboard users.

- **Behavior:** Hidden until focused, then visible at top of page

### SovereigntyStrip
Top-of-page status bar showing sovereignty status and quantum mesh health.

- **Import:** `import { SovereigntyStrip } from '@p31/ui/chrome'`

### GlowButton
Animated glow-effect button for high-emphasis actions.

- **Import:** `import { GlowButton } from '@p31/ui/chrome'`

|----------|-------------|

## Agent Prompt Rules

When generating UI, agents MUST follow these invariants:

1. Check `data-spoons` — disable motion at spoons ≤ 1
2. Use exactly **one** cyan accent per screen
3. Never pure white text (`#FFFFFF`) or pure black backgrounds (`#000000`)
4. All cards use `.glass-card` or `.glass-panel`
5. All buttons use `.btn-primary`, `.btn-secondary`, or `.btn-ghost`
6. Every component must work across spoons 0–5
7. Touch targets ≥ 48px
